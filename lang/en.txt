# character per column, then draws it proportionally) - gen_lang.py checks them:
#   T_  page titles / categories  13     I_  item names         16
#   V_  values                    13     N_  numeric values     13
#   IL_ Information-page labels   12     IV_ Information values 17
#   MSG_ popup lines              30     HINT the footer, also by pixel width
